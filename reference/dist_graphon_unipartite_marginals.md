# Graphon distance for bipartite SBM using identifiability properties of the graphons

Graphon distance for bipartite SBM using identifiability properties of
the graphons

## Usage

``` r
dist_graphon_unipartite_marginals(pis, alphas)
```

## Arguments

- pis:

  A list of two probability vectors

- alphas:

  A list of two connectivity matrices

## Value

The graphon distance between two mesoscale structure.
