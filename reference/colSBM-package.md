# colSBM: Stochastic Block Model for Collection of Networks

Finds a common mesoscale structure in a collection of networks by using
a Stochastic Block Model (SBM) extension for the joint modeling of
collection of networks as described in
[arXiv:2206.00560](https://arxiv.org/abs/2206.00560). Provides a
clustering of the nodes of each networks. Classifies networks in
sub-collections of networks with similar mesoscale structures.
