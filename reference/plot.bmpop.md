# Plot the trace of the different criteria in function of the number of clusters

Plot the trace of the different criteria in function of the number of
clusters

## Usage

``` r
# S3 method for class 'bmpop'
plot(x, type = "trace", ...)
```

## Arguments

- x:

  a bmpop object.

- type:

  The type of the plot. "trace".

- ...:

  Further argument to be passed

## Value

A plot, a ggplot2 object.
